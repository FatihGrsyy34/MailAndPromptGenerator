# English phrases that make an email read as machine-written.
# Format:  phrase => suggestion
#   - Case-insensitive; the phrase may be followed by more letters ("delve" also catches "delving").
#   - Lines starting with "re:" are regular expressions.
#   - Lines starting with "~" are soft: alone they only warn; 2+ together trigger a fix.

# --- Stock openers ---
i hope this email finds you well => open with the actual reason for writing
i hope this message finds you well => open with the actual reason for writing
i hope this finds you well => open with the actual reason for writing
i trust this finds you well => open with the actual reason for writing
i hope you're doing well => skip it unless the relationship is genuinely warm
i hope you are doing well => skip it unless the relationship is genuinely warm
i wanted to reach out => state the request directly
i am reaching out => state the request directly
i'm reaching out => state the request directly
just wanted to touch base => state the request directly
touch base => "check in" or state the request
i am writing to inform you => state the news directly
i'm writing to let you know => state the news directly

in today's => cut it unless literal

re:\b(truly|genuinely|incredibly) (appreciate|grateful|excited|sorry)\b => drop the intensifier
