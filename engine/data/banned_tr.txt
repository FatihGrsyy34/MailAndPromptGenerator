# Türkçe maillerde "bunu yapay zekâ yazmış" dedirten kalıplar.
# Biçim:  ifade => öneri
#   - Eşleşme büyük/küçük harfe duyarsızdır ve ek alabilir ("çekinmeyin" → "çekinmeyiniz" de yakalanır).
#   - "re:" ile başlayan satır düzenli ifadedir.
#   - "~" ile başlayan satır yumuşak uyarıdır: tek başına düzeltme turu tetiklemez, 2+ tanesi bir arada olursa tetikler.

# --- Çeviri kokan / kalıp açılışlar ---
umarım bu e-posta sizi iyi bulur => doğrudan konuya girin ya da somut bir bağlamla açın ("Dünkü toplantıda konuştuğumuz…")
umarım bu mail sizi iyi bulur => doğrudan konuya girin
umarım bu e-postam sizi iyi bulur => doğrudan konuya girin
~umarım iyisinizdir
re:bu (e-postayı|e-postamı|maili|mailimi) .{0,40}(amacıyla|için) (yazıyorum|gönderiyorum|iletiyorum) => amacı doğrudan söyleyin
size ulaşmak istedim => doğrudan talebi yazın
size ulaşıyorum => doğrudan talebi yazın
iletişime geçmek istedim => doğrudan talebi yazın

# --- Sohbet botu kalıntıları / kapanış klişeleri ---
başka sorunuz olursa çekinmeyin => "Sorunuz olursa yazabilirsiniz." ya da hiç yazmayın
herhangi bir sorunuz olursa çekinmeden => "Sorunuz olursa yazabilirsiniz."
çekinmeden bana ulaşabilirsiniz => "Sorunuz olursa yazabilirsiniz."
çekinmeyin => kaldırın
umarım yardımcı olur => kaldırın
umarım faydalı olur => kaldırın
yardımcı olmaktan memnuniyet duyarım => kaldırın ya da "Destek olabilirim." deyin
harika bir soru => kaldırın
kesinlikle haklısınız => "Haklısınız." yeterli
dönüşünüzü sabırsızlıkla bekliyorum => "Dönüşünüzü bekliyorum." ya da "Görüşünüzü rica ederim."
sabırsızlıkla bekliyorum => "bekliyorum"

~günümüzde

~sonuç olarak
~özetle
~kısacası

# --- Bürokratik zincir / abartı ---

re:sadece .{1,60}? değil,? aynı zamanda => "hem … hem de" ya da iki ayrı cümle
re:yalnızca .{1,60}? değil,? aynı zamanda => "hem … hem de" ya da iki ayrı cümle
