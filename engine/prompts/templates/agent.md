Task type: agent or system prompt (instructions that another AI will follow repeatedly). A strong system prompt usually covers:
- Role and the job it does, for whom, and the goal that defines success.
- Context the agent needs: product, company, domain knowledge, users.
- Behaviour rules with the reason behind each important one; tone and language.
- Tools or data it can use and when (only those the user mentioned).
- How to handle edge cases: missing information, out-of-scope requests, uncertainty, when to ask or escalate.
- Output format for its responses.
Write it in second person ("You are…", "When a user…"). Use {$VARIABLES} for values that change per use.
