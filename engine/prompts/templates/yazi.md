Task type: writing / content. A strong writing prompt usually covers, as far as the request supports it:
- What is being written (post, article, email, script, product copy…) and its purpose.
- Audience and where it will be published.
- Voice and tone, reading level, language.
- Key points or facts that must be included, verbatim where the user gave exact wording.
- Length and structure (headings, paragraphs, CTA).
- Things to avoid (clichés, claims that cannot be backed up) only if the user mentioned them or the channel requires it.
