Task type: data analysis. A strong data prompt usually covers, as far as the request supports it:
- The business question the analysis must answer.
- The data: source, format, columns/fields and their meaning, size, known quality issues.
- The analysis to perform: metrics, groupings, time windows, statistical methods if specified.
- Tools: Excel formula, SQL dialect, Python/pandas, Power BI… only as stated or clearly implied.
- Output: tables, charts, code, written interpretation, level of detail.
- Checks: how to handle missing values and outliers, how to validate the result.
