Task type: image generation. A strong image prompt usually covers, as far as the request supports it:
- Main subject and action, described concretely.
- Setting / background, composition and camera angle or framing.
- Style or medium (photo, 3D render, watercolor, flat illustration…), lighting, color palette, mood.
- Aspect ratio and exclusions if the user mentioned them or the use case implies them (e.g. banner → wide).
- Text in the image only if requested, quoted exactly.
Keep every visual detail the user gave; add only details needed to make the image coherent and mark them as assumptions.
